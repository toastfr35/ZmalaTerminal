# Remote enclosure

The remote enclosure is available as an OpenSCAD model, an STL mesh and a 3MF
slicer project. Dimensions are in millimetres.

OpenSCAD 2026.04.16 reproduced the STL byte-for-byte using ASCII STL export.
The STL is closed and the 3MF mesh has matching triangle and vertex counts.
Physical fit and printing parameters still need validation.
